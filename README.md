# Ecommerce-Product-Data-Analysis
"End-to-end e-commerce data analytics project covering data cleaning in Python (Pandas), SQL storage in MySQL, and interactive reporting/visualizations."

# 📌 Overview

* This project focuses on analyzing e-commerce sales and transactional data to identify meaningful business insights and improve decision-making.

* The project follows an end-to-end data analytics workflow, starting from data loading and cleaning in Python to SQL-based analysis, interactive dashboard development in Power BI, and final report and presentation creation.

* The main objective is to analyze sales performance, product profitability, customer demand, regional performance, and order fulfillment trends.

# 🚀 How to Run

Follow these steps to explore the project:

**Step 1: Clone the Repository**

git clone https://github.com/Deva11-mahadev/ecommerce-product-data-analysis.git

cd ecommerce-product-data-analysis

**Step 2: Open and run the Python Notebook**

* Open Ecommerce_cleaned_Project.ipynb in Jupyter Notebook.
* This file covers:
   * Data Import & Inspection (info(), describe())
   * Data Cleaning & Handling Missing Values
   * Feature Engineering and exploratory data analysis.
 
**Step 3: Load Data into SQL Database**

* Import the cleaned dataset Ecommerce Orders.sql into MySQL Workbench and run the queries against the ecommerce database.
* Run the provided SQL queries to analyze sales, products, profit, cities, and order trends.

**Step 4: Explore the Power BI Dashboard**

* Open the Ecommerce Sales Dashboard.pbix file using Power BI Desktop.
* Connect your SQL database to explore the interactive visual metrics and KPIs.

**Step 5:Review Report & Presentation**
   * Refer to the E-Commerce Product & Sales Data Analysis.pdf for a detailed summary of findings and strategic business recommendations.
   * Build presentation deck using Canva.
